# App BuscaPerto
 Este projeto foi desenvolvido com o intuito de ajudar as pessoas a encontrarem o que precisam, em relação a serviços e estabelecimentos, e que estejam próximos. O app conta com 20 categorias, essas geralmente estão muito presentes no nosso dia a dia, como, por exemplo, Supermercados, Restaurantes, Hospitais, etc... É possível ver informações como o endereço do estabelecimento, a avaliação dos usuários da Google, foto, horários de funcionamento, um botão para abrir a rota entre o usuário e o local, e um botão para ligar para o telefone do estabelecimento. Para o funcionamento da aplicação é usada a localização do GPS do celular e a API Places do Google Maps. O app também conta com um cadastro e login, além de ter a possibilidade de favoritar uma categoria, que permite que os dados da última pesquisa dessa categoria sejam vistos mesmo quando offline.
 
 ***Tutorial para rodar a aplicação***
 
 1 - Na raíz do projeto, execute "npm install" para instalar todas as dependências do projeto.
 
 2 - Em seguida, execute "react-native run-android" para executar a versão de desenvolvimento em seu celular.
 
 Caso queira apenas executar o aplicativo, instale a .apk que se encontra na pasta "apk".
